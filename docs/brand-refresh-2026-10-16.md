# Approved Taxi B&B logo

The approved first design retains TAXI above the yellow B&B mark and ESSEN below it. A transparent version is used consistently through BrandLogo in the hero, header, navigation drawer and footer. The full logo is also used in structured data and social previews. Small browser icons retain the central B&B mark for readability.

Assets are versioned v9, with explicit 960 × 431 dimensions to prevent layout shifts. No tracking behaviour changes with this release.

Validation: TypeScript, production build, prerendering and canonical/structured-data/local-font checks passed. Browser checks at 320, 390 and 1440 px verified decoded assets in every placement, navigation/subpage usage, no horizontal overflow and no JavaScript errors. New real production screenshots are captured for the Hareb case study only after deployment succeeds.
